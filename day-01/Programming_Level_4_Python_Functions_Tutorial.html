PART 1

What is a user-defined function?

A function is a named block of code that performs a particular task. A user-defined function is a function that you create to solve a problem in your program.

Everyday example: Think of a function like a coffee machine. You give it an input (water and coffee), it performs a task, and it produces an output (coffee).

1.1 The basic structure

def greet_student():
    print("Welcome to Programming Level 4!")

# Call the function to run it
greet_student()

Understand each part:

  • def tells Python that you are defining a function.
  • greet_student is the function's name. Choose a meaningful name.
  • () holds parameters, if the function needs any.
  • : starts the function body.
  • The indented print() statement is the code that runs when the function is called.
  • greet_student() calls (runs) the function.
Important: Defining a function does not automatically run it. You must call it.

1.2 Functions with parameters

A parameter is a variable listed inside the function's brackets. It allows the function to receive information.

def greet(name):
    print("Hello", name)

greet("Lerato")
greet("Thabo")

Here, name is the parameter. "Lerato" and "Thabo" are arguments supplied when the function is called.

1.3 Returning a value

Use return when a function must send a result back to the part of the program that called it.

def add_numbers(number1, number2):
    answer = number1 + number2
    return answer

total = add_numbers(10, 5)
print(total)
Output: 15. The function calculates the answer and returns it. The returned value is stored in total.

Remember: print() displays information. return sends a value back so that the program can use it.

PART 2

Using the len() function

len() is a Python built-in function. It returns the number of items in an object. When used with a string, it counts the characters, including spaces and punctuation.

student_name = "Lerato"
name_length = len(student_name)
print(name_length)
Output: 6 because “Lerato” contains six characters.

Why is len() useful?

Imagine that a registration system requires a student number to contain exactly 8 characters. You can use len() to check its length.

student_number = "12345678"

if len(student_number) == 8:
    print("Valid length")
else:
    print("Student number must have 8 characters")
The example checks the number of characters only. It does not check whether all characters are digits.
PART 3

Using the strip() string method

strip() removes whitespace from the beginning and end of a string. It does not remove spaces between words.

student_name = "   Lerato   "
clean_name = student_name.strip()
print(clean_name)
Output: Lerato

What strip() does not do

message = "  Python is great  "
print(message.strip())

Result: Python is great. The spaces between “Python”, “is” and “great” remain.

Common mistake: strip() does not remove every space in a sentence. It removes whitespace only from the two ends of the string.

Also remember that strings are not changed in place by strip(). Store the returned cleaned string if you need to use it later:

student_name = student_name.strip()
PART 4

Combining functions, len() and strip()

Now let's create a small student registration program. The program will:

  1. Ask for a student's name.
  2. Use a user-defined function to clean the name with strip().
  3. Use len() to count the characters in the cleaned name.
  4. Display the result.
def process_student_name(name):
    cleaned_name = name.strip()
    name_length = len(cleaned_name)

    print("Student name:", cleaned_name)
    print("Number of characters:", name_length)

student_name = input("Enter student name: ")
process_student_name(student_name)
Walk through the program: The function receives the entered name. strip() removes spaces at the ends. len() counts the characters remaining. The function then displays both results.
